# Ukrainian Center of Canada

Static website ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Extract the ZIP archive and upload the **contents** of the website folder to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public link after publishing.
